СЕМИНАР: A/B-ТЕСТ КАРТОЧКИ ТОВАРА

1. Распакуйте архив полностью.
2. Откройте assignment.html в браузере — это задание и описание данных.
3. Обсудите метрики с преподавателем, затем откройте seminar.ipynb.
4. Для Jupyter держите оба CSV рядом с ноутбуком.
5. Для Colab загрузите seminar.ipynb и оба CSV через панель «Файлы».

В ноутбуке есть задания с многоточиями: их нужно заполнить самостоятельно.
checkpoints.py — необязательные заготовки подготовки данных для помощи на занятии.
requirements.txt — зависимости. В Colab обычно уже есть необходимые библиотеки.

Все данные синтетические. Решения в студенческий архив не включены.
